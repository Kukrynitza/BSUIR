## Как запустить

Компиляция программы выполняется скриптом `compile.sh` из корня репозитория:

```bash
./compile.sh examples/example1.txt
```

Скрипт принимает файл с текстом программы и генерирует запускаемый файл.
На примерах с ошибками он должен завершаться с ненулевым кодом и выводить
осмысленное сообщение (что нарушено и где).

## Разрабатываемый язык

**Ledger** — язык математических вычислений. Каркас похож на JavaScript: `function`, блок `{ }`, условие в круглых скобках. Из PostgreSQL взяты явное приведение `expr::INT` и `expr::FLOAT`, проверка `BETWEEN` и связки `AND`, `OR`, `NOT`.

Переменная создаётся первым присваиванием `name = expr`. Тип выводится из значения: целое — `int`, число с точкой — `float`, `true` или `false` — `bool`. Повторное присваивание тип не меняет. `=` — только присваивание, сравнение — `==` и `!=`. Деление — `\`. Оператор заканчивается `;`. Комментарий до конца строки — `//`.

Область видимости создаёт тело `function`. Блоки операций `if`, `while`, `until` и `for` тоже записаны в `{ }`, но своей области не создают. Параметры передаются по значению, результат возвращается через `return`. Подпрограмму можно объявить в любом месте, в том числе внутри другой. Перегрузки нет.

`while (cond) { }` проверяет условие до тела. `until (cond) { }` выполняет тело хотя бы один раз и повторяет его, пока условие ложно. `for (name IN a..b BY step) { }` идёт от `a` до `b` включительно с явным шагом.


## Свойства языка по варианту

| Свойство | Значение в моём варианте |
|---|---|
| Объявление переменных | неявное: первое `name = expr` создаёт переменную |
| Преобразование типов | явное: `expr::INT`, `expr::FLOAT` |
| Оператор присваивания | одиночный: `name = expr` |
| Маркер блочного оператора | `{ }` |
| Условный оператор | `if (cond) { } else { }` |
| Оператор цикла | `while`, `until`, `for (name IN a..b BY step)` |
| Передача параметров | по значению, результат через `return` |
| Перегрузка подпрограмм | нет |
| Область видимости | глобальная и локальная у `function`; блоки `if`, `while`, `until`, `for` область не создают |
| Целевой код | байт-код JVM через ассемблер JVM |

## Встроенные типы

`int`, `float`, `bool`.

## Встроенные операции

`+`, `-`, `*`, `\`, `%`, `^`, `==`, `!=`, `<`, `>`, `<=`, `>=`, `AND`, `OR`, `NOT`, `BETWEEN`.

## Встроенные функции

`read()` читает число, `write(x)` выводит значение. `ABS(x)`, `SQRT(x)`, `SIN(x)`, `COS(x)`, `FLOOR(x)` — модуль, корень, синус, косинус и округление вниз. Константа `PI` типа `float` уже определена, присваивать её нельзя.
