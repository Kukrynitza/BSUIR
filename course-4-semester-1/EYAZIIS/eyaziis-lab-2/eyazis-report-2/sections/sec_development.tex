\section{Разработка системы распознавания языка}
\label{sec:development}

Система запускается через Docker Compose. Внутри три части: база PostgreSQL, сервер на Python и страница в браузере. Загружать можно только PDF.

Как части связаны, показано на рисунке~\ref{fig:architecture}. Сервер принимает файл, достаёт из него текст, прогоняет три метода и сохраняет результат. На странице видны язык, уверенность и время.

\begin{figure}[H]
	\centering
	\includegraphics[width=1.0\textwidth]{architecture.png}
	\caption{Структура системы распознавания языка.}
	\label{fig:architecture}
\end{figure}

При первом запуске сервер сам читает учебные тексты, строит образы языков и обучает сеть. Десять проверочных фраз тоже появляются в списке документов. Эта последовательность показана на рисунке~\ref{fig:seq-train}.

\begin{figure}[H]
	\centering
	\includegraphics[width=1.0\textwidth]{sequence_train.png}
	\caption{Обучение моделей при запуске сервера.}
	\label{fig:seq-train}
\end{figure}

Обычная проверка проще: пользователь выбирает PDF, сервер распознаёт язык и возвращает ответ каждого метода. Это показано на рисунке~\ref{fig:seq-search}.

\begin{figure}[H]
	\centering
	\includegraphics[width=1.0\textwidth]{sequence_search.png}
	\caption{Распознавание загруженного PDF.}
	\label{fig:seq-search}
\end{figure}

В браузере четыре страницы: распознавание, список документов, оценка качества и справка. После запуска интерфейс открывается по адресу \texttt{http://localhost:8080}. Список документов можно сохранить и распечатать.

Качество проверялось на десяти фразах: пять русских и пять немецких. Все три метода определили язык верно. Цифры собраны в таблице~\ref{tab:metrics}.
