\section{Постановка задачи}
\label{sec:task}

\textbf{Дано:}
\begin{itemize}
	\item растровое изображение в формате BMP размером $h \times w$ пикселей (рекомендуемый размер~--- не менее $256 \times 256$ пикселей);
	\item размер блока $r \times m$ пикселей, $4 \le r \le h$, $4 \le m \le w$;
	\item шаг сдвига блоков $s_h$ и $s_w$, $1 \le s_h \le r$, $1 \le s_w \le m$; при $s_h=r$, $s_w=m$ блоки не перекрываются, при меньших шагах соседние блоки перекрываются;
	\item число нейронов скрытого слоя $p$, $0 < p < n$, где $n$~--- длина вектора блока;
	\item порог ошибки $\varepsilon$ и ресурсный лимит эпох $T_{\max}$.
\end{itemize}

Блоки должны полностью покрывать изображение и не выходить за его границы. Если размер изображения не кратен шагу, крайний блок сдвигается к границе, поэтому на краях допускается дополнительное перекрытие.

\textbf{Требуется:}
\begin{enumerate}
	\item построить модель линейной рециркуляционной сети, решающей задачу сжатия графических данных;
	\item реализовать обучение с адаптивным коэффициентом обучения без нормировки весов (вариант 2);
	\item выполнить сжатие и восстановление изображения;
	\item построить семейства графиков зависимостей параметров модели;
	\item дать ответы на контрольные вопросы;
	\item оформить письменный отчёт.
\end{enumerate}

Значения интенсивности пикселей приводятся к диапазону $[-1,\,1]$:
\begin{equation}
	c = \frac{2C}{C_{\max}} - 1, \qquad C_{\max}=255,
	\label{eq:norm}
\end{equation}
где $C$~--- исходное значение канала, $c$~--- нормированное значение. Один блок цветного изображения порождает вектор длины $n = r \cdot m \cdot |S|$, где $|S|$~--- число цветовых каналов ($|S|=3$ для RGB). Векторы блоков располагаются по строкам матрицы $X$ размера $Q \times n$, где $Q$~--- фактическое число блоков.

Коэффициент сжатия задаётся формулой методических указаний:
\begin{equation}
	Z(Q,n,p) = \frac{Q\,n}{2 + (n+Q)\,p}.
	\label{eq:Z}
\end{equation}
Значение $p$ выбирается пользователем так, чтобы выполнялось $Z(Q,n,p) > 1$.
