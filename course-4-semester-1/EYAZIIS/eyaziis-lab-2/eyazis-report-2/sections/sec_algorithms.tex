\section{Алгоритмы распознавания языка}
\label{sec:algorithms}

По варианту~13 система определяет язык PDF-документа: русский или немецкий. Используются три метода построения и сравнения поисковых образов: коротких слов, частотных слов и нейросетевой (многослойный перцептрон на символьных N-граммах).

Общая схема совпадает с описанной в задании. Для каждого языка по обучающему корпусу строится поисковый образ языка (ПОЯ). Для входного документа по тем же правилам строится поисковый образ документа (ПОД). Стратегия сравнения выбирает язык с наибольшей оценкой принадлежности (для словесных методов \mdash произведение вероятностей лексем, для нейросети \mdash вероятность класса). Дополнительно между ранжированными профилями считается расстояние Out-of-Place.

Обучающий корпус лежит в каталоге \texttt{corpus/train}: по семь текстов медицинской тематики на каждый язык. Объём русской части составляет около 50~Кбайт, немецкой \mdash около 85~Кбайт, что укладывается в требование задания (от 20 до 120~Кбайт). Эталонная разметка для оценки качества хранится отдельно в \texttt{qrels.json}: десять коротких фраз с заранее известным языком. Эти фразы не входят в обучение.

Текст сначала приводится к нижнему регистру, буква <<ё>> заменяется на <<е>>. Токенизация допускает внутренние дефисы и немецкие умлауты. Русские словоформы лемматизируются анализатором \texttt{pymorphy3}; немецкие приводятся к нижнему регистру. Стоп-слова для построения ПОЯ не отбрасываются: служебные лексемы как раз различают языки.

Метод коротких слов включает в ПОЯ лексемы длиной не более пяти символов, встретившиеся в обучающем корпусе более трёх раз. Вероятность лексемы \mdash отношение её частоты к сумме частот всех лексем профиля. Лексеме, отсутствующей в ПОЯ, назначается малая сглаживающая вероятность. Принадлежность документа языку оценивается как произведение вероятностей коротких лексем документа:

\begin{equation}
	P(\mathrm{lang}\mid\mathrm{doc}) = \prod_{l \in L_{\mathrm{short}}} P(l\mid\mathrm{lang}).
	\label{eq:short}
\end{equation}

На практике вычисляется сумма логарифмов, чтобы избежать потери точности. Выбирается язык с наибольшим значением. Профиль коротких слов шире топ-50, поэтому сравнение и расстояние ОоП на длинном документе занимают больше времени, чем у частотного метода.

Метод частотных слов строит ПОЯ из пятидесяти самых употребительных лексем корпуса без ограничения длины. С документом сравниваются только слова из объединения языковых пятёрок десятков. Оценка имеет тот же вид, что и~\eqref{eq:short}, но по этому узкому словарю. Поэтому метод быстрее: после разбора текста почти вся работа сводится к просмотру короткого списка.

Нейросетевой метод использует \texttt{MLPClassifier} из \texttt{scikit-learn}. Признак \mdash бинарное присутствие символьной N-граммы ($N = 1,\ldots,5$) в тексте. В словарь признаков попадают N-граммы, встретившиеся не менее чем в двух обучающих документах. Сеть содержит два скрытых слоя (128 и 64 нейрона), функция активации \mdash ReLU, оптимизатор \mdash Adam. На выходе \mdash две вероятности классов. Этот метод не строит словесный ПОЯ и не считает ОоП по лексемам.

Расстояние Out-of-Place сравнивает два списка, упорядоченных по убыванию частоты. Для каждой единицы профиля берётся модуль разности рангов; отсутствующему элементу назначается штраф, равный длине более длинного списка:

\begin{equation}
	d(A,B) = \sum_{g \in A \cup B} \lvert \mathrm{pos}_A(g) - \mathrm{pos}_B(g) \rvert.
	\label{eq:oop}
\end{equation}

Абсолютное значение ОоП растёт вместе с длиной профилей, поэтому его нельзя напрямую сравнивать между методом коротких слов и методом топ-50. Решение о языке словесные методы принимают по вероятности~\eqref{eq:short}, а не по минимуму ОоП.

Время каждого словесного метода измеряется от сырого текста: перед запуском сбрасывается кэш лемматизации, чтобы частотные слова не получали <<бесплатную>> предобработку после коротких слов. Нейросеть засекается отдельно по извлечению N-грамм и прогону сети.
